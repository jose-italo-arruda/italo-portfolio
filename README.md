# Portfólio — Ítalo Arruda (GitHub Pages)

Este repositório contém um portfólio 100% **HTML + CSS + JavaScript puro**, sem frameworks e sem CDNs.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub (ex.: `italo-portfolio`).
2. Faça upload de **todos** os arquivos/pastas deste projeto (principalmente `index.html` e `assets/`).
3. Vá em **Settings → Pages**.
4. Em **Build and deployment** selecione:
   - **Source:** Deploy from a branch
   - **Branch:** `main` (ou `master`) e **/ (root)**
5. Salve. O GitHub mostrará a URL do site.

Dica: se quiser usar um domínio personalizado, configure em **Pages → Custom domain**.
